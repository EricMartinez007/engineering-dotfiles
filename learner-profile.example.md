# Learner profile

Copy this file to `~/.claude/learner-profile.md` and fill it in with your own
background. The `teacher` agent reads it to calibrate how it explains code: the
right depth, the right analogies, what to explain from fundamentals versus treat
as known. If you skip this, the teacher falls back to a sensible default level.

The install script copies this template into place for you on first run, so you
can just edit `~/.claude/learner-profile.md` directly.
